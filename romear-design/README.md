# Romear Figma design

[Open design](https://www.figma.com/design/KlJVJFTdJpKzwi5gAs5qIL)

38 editable frames covering the 35 numbered screens, three welcome slides, and both ticket tabs. Six flow boards, color variables, Outfit text styles, reusable button/input/badge foundations, and linked primary prototype paths.

The map, ticket QR, liveness view, and voice waveform are static design representations. Photography uses sample Unsplash assets; the sports venue uses an editable badminton-court illustration. These are design assets rather than live location, payment, verification, or recording functionality.

The specification's illustrative name, age, and birthday values are preserved; they should be derived from profile data during implementation.
